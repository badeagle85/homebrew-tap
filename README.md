# homebrew-tap

[badeagle85](https://github.com/badeagle85) 의 macOS 앱 설치용 Homebrew tap.

## 쓰는 법

```bash
brew tap badeagle85/tap
```

| 앱 | 설치 |
|---|---|
| [아빠안잔다](https://github.com/badeagle85/dads-watching-this) — AI 세션이 도는 동안 맥을 안 재운다 | `brew install --cask --no-quarantine dads-watching-this` |

`--no-quarantine` 은 Apple 공증(연 $99)을 받지 않아서 필요하다. 소스는 각 저장소에 전부 공개되어 있다.
